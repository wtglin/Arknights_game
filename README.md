# 🎮 Arknights Fan Game - 截云 vs 重岳

> 🎬 *「片场实况素材 · 年大导演监制中」*  
> 一款基于 **C++ & SFML 3.0+** 开发的轻量级双人对战小游戏，还原明日方舟角色特色技能与战斗体验！

---

## 📦 快速开始

### ⚠️ 重要提示
```
❗ 运行前请确保将所有图片资源按现有格式打包，放置于项目根目录下的 `graphics/` 文件夹中
❗ 否则可能导致角色贴图、UI 界面等资源加载失败
```

### 🔧 环境要求
| 组件     | 版本要求                               |
| -------- | -------------------------------------- |
| 编译器   | 支持 C++17 及以上 (GCC/Clang/MSVC)     |
| 图形库   | [SFML 3.0+](https://www.sfml-dev.org/) |
| 构建工具 | CMake 3.10+ 或 Makefile                |

### 🚀 编译运行
```bash
# 克隆项目
git clone https://github.com/yourname/Arknights_game.git
cd Arknights_game

# 创建构建目录
mkdir build && cd build

# CMake 配置 & 编译
cmake ..
cmake --build .

# 运行游戏
./Arknights_game
```

> 💡 Windows 用户可直接使用 `Visual Studio` 打开 `.sln` 文件编译运行

## ⚔️ 战斗系统

### ❤️ 基础属性
```cpp
struct Fighter {
    int hp = 100;           // 生命值
    float damage = 1.0f;    // 伤害系数
    float defense = 0.0f;   // 🚧 防御系统待实现
    bool isStunned = false; // 控制状态
};
```

### 💥 攻击机制

| 角色     | 普攻伤害 | 技能期间伤害  | 音效特色                   |
| -------- | -------- | ------------- | -------------------------- |
| **截云** | 6 HP     | 9 HP (+50%)   | 🗡️ 拔刀脆响                 |
| **重岳** | 5 HP     | 10 HP (+100%) | 🎵 "劲发江潮落，气收秋毫平" |

### ✨ 技能详解

#### 🌩️ 截云 - 「白霄·绝影」
```
🔹 冷却时间：11 秒
🔹 增益效果：4 秒内伤害 ×1.5
🔹 技能伤害：20 点爆发
🔹 控制效果：命中后敌方定身 3 秒
🔹 战术定位：爆发 + 控制，适合抓失误反打
```

#### 💃 重岳 - 「我去！我喜欢跳舞！」
```
🔹 冷却时间：20 秒  
🔹 增益效果：6 秒内伤害 ×2.0 + 30% 伤害减免
🔹 特殊机制：技能期间按 Q 可瞬移（饼干化🍪）
🔹 战术定位：持续压制 + 高机动，适合拉扯消耗
```
